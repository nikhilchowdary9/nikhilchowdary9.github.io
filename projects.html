Agentic Script-to-Visual Generation Pipeline

An end-to-end workflow that takes a raw script and turns it into a structured screenplay, a shot-by-shot prompt breakdown, and a rendered visual storyboard. I orchestrated LLM agents to handle the text decomposition stage, then wired that output into open-source diffusion models running locally — which meant getting hands-on with VRAM budgeting and model quantization to keep render times reasonable on consumer hardware.

SPEECH · METRIC LEARNING
Voice Recognition & Speaker Identification

A one-shot learning system for speaker identification, built around a 15-layer CNN trained on VoxCeleb audio spectrograms. I used Siamese networks with a triplet-loss objective and cosine distance so the model could recognize speakers it had never encountered during training — and it held up, reaching an AUC of 0.94 on unseen speakers.

FROM SCRATCH · NLP FUNDAMENTALS
Word2Vec, Rebuilt From Scratch

A from-scratch PyTorch implementation of Word2Vec, trained on an RTX 5060 Ti — less about needing another embedding model and more about forcing myself to fully understand what off-the-shelf implementations abstract away. The main engineering problem turned out to be data throughput rather than model design: I hit memory and performance bottlenecks partway through training and resolved them by moving to a streaming IterableDataset approach instead of loading everything into memory up front.
